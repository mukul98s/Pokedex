## Getting Started

### Prerequisites

- Node.js (v22.13.0)
- npm (v11.1.0)

### Installation

First, run the development server:

```bash
npm install
npm run build
npm run start
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Pages

- Home: `/`
- Pokemon Details: `/pokemon/:id`

## API
